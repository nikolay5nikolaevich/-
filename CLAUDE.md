# Вода и молоко — лендинг

Редизайн водаимолоко.рф. «Вода и молоко» — B2B-поставщик для кофеен в СПб и ЛО: молоко, сливки, вода, сиропы, стаканы, кофе и чай. Это не ферма.

Сайт — слайд-шоу из пяти полноэкранных статичных кадров (по образцу `референсы/основной механизм/pinterest-video.mp4`). Скролл, свайп, клавиши или клик переключают сцену. Фото внутри кадра не анимируются, движение есть только при смене сцены и в появлении текста.

Вся визуальная часть описана в **[DESIGN.md](DESIGN.md)**. Это источник правды: перед любой вёрсткой читай его. Если решение меняется, сначала правь DESIGN.md, потом код.

## Стек и команды

- Vite + React, без UI-библиотек и CSS-фреймворков. Стили на обычном CSS, переходы на CSS `transform`/`opacity`. WebGL и canvas не нужны.
- `npm run dev` — локальный сервер, `npm run build` — статика в `dist/`.
- Новые зависимости не добавлять без явной причины. Шрифты подключаются с Google Fonts.

## Контент

- Весь текст на сайте на русском. Тон премиальный и короткий.
- Факты о компании (не выдумывать других): доставка пн–сб, заказ от 4000 ₽, 90% матрицы кофе-бара, СПб и ЛО, телефон +7 (812) 950-66-70.
- Позиции каталога и цены пока заглушки. Помечай их явно, чтобы потом найти и заменить.
- Заявки уходят в Telegram @volopopi через `t.me/volopopi?text=...` и копию в буфер (DESIGN.md §5). Бота и бэкенда пока нет.

## Ассеты

- `assets/scenes/01…05-*.png` — готовые кадры сцен. Это исходники, их не перезаписывать. Для сайта экспортировать в `public/img/scenes/*.webp` (DESIGN.md §8).
- `assets/logo-hd.png` — фирменная эмблема с коровой, обязательна в шапке. На сайте используется её копия `public/img/logo.png`. `assets/logo-original.png` — оригинал с сайта клиента, только референс.
- `assets/catalog-site/` — фото каталога с текущего сайта. Для сайта они лежат в `public/img/catalog/*.webp`.
- `public/img/milk*.webp` и `water*.webp` остались от старого героя со всплесками и в новом дизайне не используются.
- Новые картинки генерирует Codex CLI. Промпт передаётся через stdin, потому что `-i` принимает несколько файлов и «съедает» позиционный аргумент:
  ```sh
  echo "<промпт>. Save the PNG into the current directory as <name>.png." \
    | codex exec --skip-git-repo-check --sandbox workspace-write -i <референс.png> -
  ```
  Запускать из `assets/`. После генерации посмотри картинку, прежде чем использовать.

## Проверка

- Перед тем как сказать «готово», открой страницу в браузере. Проверь ширины 375 / 1024 / 1440.
- Проверь все способы переключения: колесо и тачпад (один жест — одна сцена), свайп, клавиши, клик, индикатор, ссылки шапки, хэш в URL. Проверь также `prefers-reduced-motion`.
- Горизонтального скролла на мобилке быть не должно.
